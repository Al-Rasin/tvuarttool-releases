## Install (Bangla)
1. উপরের লিংক ফোনে খুলুন, APK ডাউনলোড হবে।
2. ডাউনলোড শেষ হলে ফাইলটি খুলুন।
3. "Install unknown apps" চাইলে → Allow / অনুমতি দিন।
4. Install চাপুন।

App already installed? New version comes inside the app: home screen shows **UPDATE** → tap → Install.
অ্যাপ আগে থেকে থাকলে: হোম স্ক্রিনে **UPDATE** আসবে → চাপুন → Install।
